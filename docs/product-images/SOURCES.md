# Bondex Notch product artwork

The mac desktop after dark layout draws its palette from the product screenshots.
Open the HTML files in `source/` to edit the artwork. Ubuntu is used for English and Kantumruy Pro for Khmer. Font licenses are included.

The artwork uses original project logos and interface captures. Workflow graphics illustrate the product's documented capabilities.

Repository: https://github.com/RithyBondeth/Bondex-Notch

Published product previews from the official app website; not independent captures of a running Mac app.
